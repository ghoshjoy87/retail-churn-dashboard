# Data Documentation

This directory documents the data used by the customer retention decision-support artefact.

## Dataset Source

The project uses the publicly available **E-Commerce Customer Churn Analysis and Prediction Dataset** from Kaggle.

The original dataset contains:

- 5,630 customer records
- 20 predictor variables
- One binary target variable: `Churn`
- Numerical and categorical customer attributes
- Customer demographic, behavioural, transactional, and service-related information

The raw dataset is not redistributed in this repository. Users should obtain the original dataset from its official source.

## Adapted RFM Segmentation

The project implements an adapted Recency–Frequency–Monetary (RFM) customer segmentation framework.

Because the source dataset does not contain customer-level transaction revenue, total expenditure, or purchase value, `CashbackAmount` is used as a proxy for the Monetary component.

`CashbackAmount` should not be interpreted as equivalent to:

- customer expenditure;
- revenue;
- profitability;
- customer lifetime value.

The resulting RFM segmentation therefore represents relative behavioural and monetary-proxy positioning within the available dataset.

## Processed Data Files Used by the Prototype

The deployed decision-support application uses processed analytical outputs generated by the research notebooks.

### `rfm_segmented_data.csv`

Contains customer behaviour segmentation results generated through the adapted RFM framework.

### `final_recommendation_engine_output.csv`

Contains integrated customer-level decision-support outputs, including churn probabilities, behavioural segment information, retention priority, SHAP explanations, and manager-oriented recommendations.

### `local_shap_reasons.csv`

Contains business-readable customer-level explanations derived from SHAP analysis.

### `dice_counterfactual_highrisk.csv`

Contains DiCE counterfactual outputs generated for selected high-risk customers.
