# System Architecture

This directory contains the architecture documentation for the developed Explainable AI-enabled Business Intelligence decision support system.

## Files

- `Final_System_Architecture.drawio` – editable source diagram
- `system_architecture.png` – exported architecture image for direct viewing

The architecture illustrates the integration of:

- data preparation;
- customer behaviour segmentation;
- Random Forest churn prediction;
- SHAP explainability;
- DiCE counterfactual analysis;
- recommendation generation;
- retention prioritisation;
- Streamlit-based managerial decision support.
